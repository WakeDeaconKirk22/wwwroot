By completing this project, I gained hands-on experience with Microsoft's Azure AI services by building and monitoring an end-to-end speech processing pipeline. Specifically, this project demonstrates the ability to:

Provision and configure Azure AI Speech, Azure AI Language, and Azure Application Insights using both the Azure Portal and Azure CLI.
Convert recorded or uploaded audio into text using the Azure Speech SDK in both batch and real-time streaming modes.
Generate natural-sounding speech from text using Azure Text-to-Speech with customizable voices.
Process speech transcription results with Azure AI Language to extract entities and key phrases.
Work with common audio formats and encoding standards, including WAV, MP3, and OGG, while managing sample rates for cloud-based AI services.
Instrument an AI pipeline with Azure Application Insights by collecting structured telemetry, custom events, custom metrics, and distributed traces.
Monitor application performance and analyze telemetry data using Azure Monitor and Kusto Query Language (KQL).
Configure Azure Monitor alerts to detect and respond to AI pipeline performance or quality degradation.
(CSC 691) Evaluate speech transcription confidence scores and implement fallback and retry strategies to improve transcription reliability.

This project highlights practical experience in developing, monitoring, and evaluating cloud-based AI applications that integrate speech recognition, natural language processing, and application observability.
